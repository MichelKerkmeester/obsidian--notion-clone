# Human Verification Checklist

> **Companion doc, not a duplicate.** [`operator-checklist.md`](operator-checklist.md) is
> generated by `tools/naming/build-operator-checklist.mjs` from every phase's own `goal.md` —
> edit the phase docs, never that file. This document is written by hand for the same ids, turned
> into steps you can run from a phone in one sitting. If the two ever disagree, `operator-checklist.md`
> is the source of truth and this file is stale.

**Build under test:** `0.0.36`, cut at `04524885`. Installed via the vault's plugin folder,
`obnotion` (the id `note-database` used to publish under is gone as of the rename).

**How to record a result:** reply in this chat, one line per row —
`row N pass` or `row N fail: <what you saw>`. The orchestrator files it against the row's id(s).
You do not need to tick anything in this file or in `operator-checklist.md` yourself.
