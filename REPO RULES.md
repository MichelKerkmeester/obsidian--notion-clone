# Repo Rules — Obsidian Note Database

> Per-repository companion to `AGENTS.md`. That file carries rules true in every repository; this one carries what is true only here — the gate, the paths, the traps. Its verification commands bind exactly as `AGENTS.md`'s do.
>
> When this file and `AGENTS.md` disagree about a *rule*, `AGENTS.md` wins. About a *path, command or number*, this file wins.
